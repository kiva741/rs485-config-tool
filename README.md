485 传感器配置工具 V1.0
一个给 RS-485 传感器用的 Windows 上位机：插上 USB 转 485，点一下就能自动找到设备，直接看数、改参数、存历史。
免安装，解压即用，支持中英文界面。

这是干什么的
厂里/现场常见的 RS-485 传感器（温湿度、二氧化碳、土壤、水质、气体、倾角、雨量……）出厂时只给一张寄存器表，要读数、要改报警上下限，就得有个上位机。

这个软件就是干这个的：

插上就能用：自动找串口、自动试波特率、自动读从站地址，正常 1 秒内出结果，不用背波特率
看数：仪表盘 + 通道明细，带质量状态（正常 / 超时 / 校验错 / 从站异常），哪个通道出问题一眼能看到
改参数：报警上限/下限、回差、微调、从站地址、波特率——写完自动回读核对，设备没接受会直接告诉你
存历史：读到的数自动存本地 SQLite，可以看趋势曲线、导出 CSV；不会自动删，想清哪个型号、清几天前的，自己点
点表外的新设备：内置点表不认识的型号，可以自己加（填起始地址、寄存器数、数据类型、字节序），也能复制现成型号改两个地址
调试：内置串口调试台，可以手敲十六进制指令、自动算 CRC，也能直接看设备主动上报的字节
主要功能一览
分类	功能
通信	Modbus RTU（03/04/06）、自动搜索端口/波特率/从站地址、断线自动重连（串口改名也能找回）
读数	实时仪表盘、通道明细、质量状态、通道异常时给出排查建议（查 A/B、波特率、地址冲突…）
参数	报警上下限、回差、微调、从站地址、波特率读写 + 回读核对
型号	内置点表、自定义型号、型号图片（自动裁白边）、型号与图片打包导出/导入
数据	趋势曲线（最多 4 条同时看、左右双轴）、历史数据手动清理、CSV 导出（含单位/质量）
工具	进制转换、数据类型助手（读数对不上时帮你猜类型/字节序/小数位）、串口调试台、一键反馈包
使用	中英双语、5 套配色、普通/高级模式、小屏自适应、在线更新、首次使用三步引导
怎么用
解压整个文件夹（别只拷 exe，旁边的 485_Ch.csv 是内置型号表）
插上 USB 转 485，接好 A/B 线，给设备上电
双击 485传感器配置工具.exe
顶部点「自动搜索波特率/地址」→ 选型号 → 点「连接设备」
第一次打开会有三步引导，跟着点就行。

详细说明看压缩包里的 使用说明.txt。
